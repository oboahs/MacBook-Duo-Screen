## DhananjayBhosale/MacDuo

Repository: https://github.com/DhananjayBhosale/MacDuo

MacBook Duo Screen V2's ScreenCaptureKit overlay architecture and the core bottom-hinge Duo compensation model were adapted from / informed by MacDuo. The implementation in this repository is reduced and modified for Intel MacBook Pro hardware and uses its own verified LAS reader.
